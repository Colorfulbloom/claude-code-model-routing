# Project facts (reviewed)

Owner-approved facts promoted from HiveMind. Only deep-reasoner edits this file, and only after the owner approves a promotion. Limit: 60 lines.

- T-7629 Full suite: from the repo root, `/usr/bin/python3 -m unittest discover -s tests` runs 3575 tests (88 skipped) in about 370 seconds (2026-11-07, development at ff41524). 86 of the skips need `MR_E2E=1`, and the owner runs those. The other two need `MR_DOCS_LIVE=1` and `MR_SUBAGENT_DOCS`. Run it alone, not beside a harness batch, and give its log a per-branch name, because background leads of one session share a scratchpad.
- T-5589 Test subsets: `discover -s tests -k <pattern>` or `-p test_x.py` works; dotted names such as `tests.test_x` fail with "No module named 'helpers'".
- T-c826 MR_TEST_TMP is optional: tests/helpers.py creates the directory when it is set and missing; unset means the system temp dir. `_tmp_base` refuses a base inside a git work tree (any `.git` entry at or above its real path), so MR_TEST_TMP must sit outside every repo.
- E-5b16 Write core: `edit_store.py` alone writes settings.
- T-07ef Settings harness: `dashboard/experiments/harness/` measures precedence with no real API call (fakeapi.py on 127.0.0.1, throwaway HOME). `claude -p "/effort status"` and `"/autocompact"` send no request. Never run a batch as a check.
- D-1534 Doc anchors: check code.claude.com anchors against the rendered HTML `id="..."` attributes, not .md heading slugs. Python urllib needs a custom User-Agent; the default gets 403.
- D-b739 Fixture ignores: a global gitignore can drop `.claude/settings.local.json`; the repo `.gitignore` negates it for `tests/fixtures/**`. Check with `git check-ignore -v`.
- K-6860 Nested `:has()`: it is invalid CSS, so the browser drops the whole rule with no error. Check Settings rail padding by computed value, not by `--s4-foot`.
- U-0aa1 Undo history: edit ledgers are per file, and history merges the layers by (time, seq). Server `rows[-1]` is one file's newest row and page `rows[0]` is the project's newest, so a row with `undoable` or `undo_anyway` can still sit in Older backups.
- R-06c2 Rule count: adding or removing a rule in `dashboard/rules.json` breaks `test_api_rules` until the All, Tested, Documented and Assumed texts in `tests/e2e_checks/rules.json` change and `docs/rules-reference.md` is rebuilt with `/usr/bin/python3 dashboard/reference_page.py`.
- N-9919 Settings node checks: `tests/js/settings_checks.mjs` reads payloads from `MR_PAYLOADS`, which `tests/test_settings_js.py` fills from its CASES list, so run it through that test. A fixture a check names with `real(...)` joins CASES, or the check fails with ENOENT.
- D-c684 macOS traps: `/usr/bin/python3` adds CPATH, LIBRARY_PATH, SDKROOT, MANPATH and `__CF_USER_TEXT_ENCODING` to every child, so env-leak asserts ignore them (SYSTEM_ADDED in `tests/test_harness_guard.py`). BSD sed has no `\b` and exits 0 having changed nothing, and there is no `timeout` command. Rewrite files with Python `re.sub`.
- C-06bf Probe copies: exclude the anchored `/.claude`, or rsync carries the owner's `settings.local.json` into the copy. A bare `.claude` also drops `tests/fixtures/demo/projects/*/.claude`, so the demo shows Driftwood, Saltmarsh and Tidewater reporting as `no_claude_folder` instead of `ok`. A shell that exports a throwaway HOME also shows that file as untracked in `git status`, so run git without the export.
- W-7178 Browser-free JS checks: `tests/test_shell_js.py` runs `tests/js/checks.mjs` on fakedom, and `tests/test_pages_js.py` runs the real app.js over `pages.mjs` and `tests/e2e_checks/`. Both skip without node. Modules hold state, so each check imports a fresh copy (`app.js?run=N`, `pages/x.js?copy=N`). h() sets value as a property.
- K-819f String keys: `tests/test_static_strings.py` counts a key as used only in a literal `t("key"` or `tn("key"` call, so a key passed through a helper such as `pathLine("key", ...)` reads as unused.
- T-3ad1 Test files: `NoHomePathsInTestsTest` bans home path prefixes in `tests/*.py`, so sample paths start at `/work/`; `tests/fixtures/` is not scanned. Import a test module whole (`import test_x as x`), because `from test_x import TestClass` makes discover run that class twice.
- D-3ca7 Worktree agents: the worktree guard refuses `git -C <dir>`, a command named by a variable or by a quoted path with a space, any command that sets HOME, a script path built from `$HOME` or `${VAR:-x}`, and a heredoc that mentions git. Some runs also refused other heredocs, for loops and a pipe into diff. Use one plain command per call with literal paths, write scripts with Write, and compare with a ref through `git archive <ref> <path> | tar -x -C <scratch>`. A new isolation worktree starts at origin/main, not development.
- L-13fb Plugin payload: any change to dashboard/, agents/, rules/, hooks/ (the HOOK_NAMES files), skills/, install.py, agent_md.py or docs/model-routing-reference.md needs a version bump in `plugins/routing-dashboard/.claude-plugin/plugin.json` and `python3 tools/build_plugins.py`, or test_plugin_build fails. G-3e60: `hooks/hivemind_lib.py` ships in both the routing-dashboard and hivemind payloads, so a change to it needs both plugin.json bumps. The build reads only tracked files (`git ls-files`), so stage a new source file first, or the build leaves it out and `--check` still passes.
- I-14ae Browser opens: use `webbrowser.get().open(url)`. `webbrowser.open` falls through to the next registered browser (macOS `open`) when one fails, so a test with a failing browser stub opens real tabs.
- A-3436 Arrange cells: band cells are `a.s4-stat` links at rest and `div.s4-stat` only while Arrange is pressed, so an E2E wait on the div selector before pressing Arrange never succeeds. Wait on the `a.s4-stat` cells first.
- V-e876 Byte prefilters: a byte prefilter needle for a JSON key keeps its colon (`b'"toolUseResult":'` in `dashboard/transcripts.py`). A bare needle also matches a string value, such as a Grep pattern in a tool input, and that row's usage is lost.
- H-da08 Tally expiry: `hivemind_lib.py apply` drops a token-tallies.md row once more than `tally_expiry_active_days` active days follow its last_date (6 in this store; without the key it follows `expiry_active_days`). Active days are the local `active-days.txt` plus git commit dates, not calendar days. An expired row's line moves to `archive/token-tallies.md` and its raw samples to `archive/tallies.json`. `tally_samples_max` caps samples per row, not rows.
- L-bd45 Launcher guard: each plugin guards its script with a PreToolUse hook in `plugins/<plugin>/hooks/hooks.json` (`if: "Bash(python3 *bin/<script>*)"`, `onFailure: block`), not a skill `disallowed-tools` deny, because that deny leaked into the next slash command and denied its `!` line. On Claude Code 2.1.302 the hook skips a skill's `!` line and fires for every other Bash call, in any agent, turn or permission mode. Rerun `tools/skill_probe/probe.py` after every Claude Code upgrade.
- L-979a Guard scripts: with the plugins on, agents can't run `bin/routing-dashboard` or `bin/hivemind` through Bash, py_compile included. Test them as subprocesses with `["guard"]` and JSON on stdin, through `tests/test_plugin_launcher.py` and `tests/test_plugin_hivemind.py`. Both scripts keep one split logic, held to the same GUARD_CASES.
- R-7c9c Agent file loads: an agent `.md` loads only with a non-empty name and description; without a description it gets case `no_description` and no model or effort entries (`dashboard/resolve.py`). No collector reads plugin agent folders or plugin settings, so the plugin layer of agent-file-location-order is never fed.
- V-0acf Live API: `/api/live` serves one project (`project=all` gets 400 `pick_project`) and only sessions with a request in the last `RUNNING_MINUTES` (30); it has no `at` parameter. It ignores records after now, so a fixture clock replays minute T inside that window. `server._fixture_now` takes session.json `now` only as ISO with an offset, else it silently uses the real clock.
- C-1ff9 Edit scope: `edit_store.py` writes only the three settings files a project key and layer (user, project, local) name. `api_edit` SETTINGS edits four keys (effortLevel, maxEffortLevel, model, autoCompactWindow), and `json_edit` edits object paths only (`parent_not_object`) with no array append. Agents, skills, CLAUDE.md, MCP files or list values need new targets and operations.
